================================================================================
  Kindle Screenshot Tool - 実行ファイル版
================================================================================

■ 使い方

1. Kindle for PC でキャプチャしたい本を開く
2. KindleScreenshot.exe をダブルクリック
3. タイトルを入力（空白の場合は現在時刻が使用されます）
4. 自動的にページがキャプチャされます
5. 本の最後まで到達すると自動的に終了します

■ 保存先

デフォルト: e:\kss\[タイトル名]\
- 001.png, 002.png, 003.png ... という形式で保存されます

■ 操作方法

- 中断したい場合: Ctrl + C を押す
- ページめくり: 左矢印キー（自動）
- フルスクリーン切替: F11キー

■ 設定変更

プログラムの設定を変更したい場合は、kindle_screenshot.py を編集してください:

- BASE_SAVE_FOLDER: 保存先フォルダ（デフォルト: e:\kss\）
- PAGE_CHANGE_KEY: ページめくりキー（デフォルト: left）
- KINDLE_FULLSCREEN_KEY: フルスクリーンキー（デフォルト: f11）
- WAIT_SEC: ページ読み込み待機時間（デフォルト: 0.15秒）

設定を変更した後は、再度 build_exe.bat を実行してEXEを再ビルドしてください。

■ トラブルシューティング

Q: 「Kindleが見つかりません」と表示される
A: Kindle for PC を起動してから実行してください

Q: ページが正しくキャプチャされない
A: WAIT_SEC の値を大きくしてみてください（例: 0.3）

Q: 保存先フォルダが見つからない
A: e:\kss\ フォルダを事前に作成するか、BASE_SAVE_FOLDER を変更してください

■ システム要件

- Windows 10/11
- Kindle for PC がインストールされていること
- 画面解像度: 1920x1080 以上推奨
