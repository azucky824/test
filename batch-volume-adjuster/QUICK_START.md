# クイックスタートガイド

## 1分で始める音量一括調整ツール

### ステップ1: インストール

```bash
# 1. FFmpegのインストール (まだの場合)
# Ubuntu/Debian:
sudo apt-get install ffmpeg

# macOS:
brew install ffmpeg

# 2. Pythonパッケージのインストール
cd batch-volume-adjuster
pip install -r requirements.txt
```

### ステップ2: 起動

**Linux/macOS:**
```bash
./run.sh
```

または

```bash
python3 volume_adjuster.py
```

**Windows:**
```
run.batをダブルクリック
```

または

```
python volume_adjuster.py
```

### ステップ3: 使い方

1. **ファイルを追加**
   - ウィンドウにファイルをドラッグ&ドロップ
   - または「ファイルを追加」ボタンをクリック

2. **音量を調整**
   - スライダーを左右に動かす
   - 右に動かすと音量が上がり、左に動かすと下がります

3. **実行**
   - 「音量調整を実行」ボタンをクリック

4. **完了！**
   - 処理されたファイルは元のファイルと同じ場所に保存されます
   - ファイル名に `_adjusted` が付きます

## よくある使い方

### 音量を2倍にする
スライダーを約 **+6dB** に設定

### 音量を半分にする
スライダーを約 **-6dB** に設定

### 動画の音声だけ調整
- MP4やAVIファイルも対応しています
- そのままドラッグ&ドロップしてください

### MP3に変換しながら音量調整
- 「出力形式」で「MP3」を選択
- 音量調整と同時にフォーマット変換ができます

## トラブルシューティング

### エラーが出る
1. FFmpegがインストールされているか確認
   ```bash
   ffmpeg -version
   ```

2. 必要なパッケージがインストールされているか確認
   ```bash
   pip list | grep pydub
   pip list | grep tkinterdnd2
   ```

### ドラッグ&ドロップできない
- tkinterdnd2がインストールされていない可能性があります
- 「ファイルを追加」ボタンで代替できます

## 注意事項

- 元のファイルは変更されません（安全です！）
- 処理には時間がかかる場合があります（ファイルサイズによる）
- 音量を上げすぎると音割れする可能性があります（+10dB以上は注意）
