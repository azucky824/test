# PDF圧縮ツール

PDFファイルを簡単に圧縮できるGUIアプリケーションです。画像品質を調整することでファイルサイズを削減します。

## 特徴

- **使いやすいGUI**: シンプルで直感的なインターフェース
- **ドラッグ&ドロップ対応**: ファイルを簡単に追加
- **複数の圧縮レベル**: 用途に応じて選択可能
  - 低圧縮（高品質）: 画像品質 90%
  - 中圧縮（標準）: 画像品質 70%
  - 高圧縮（低品質）: 画像品質 50%
  - カスタム: 10-100%の範囲で自由に調整
- **サイズプレビュー**: 圧縮前に推定サイズを確認
- **進捗表示**: リアルタイムで処理状況を確認

## 必要環境

- Python 3.7以上
- tkinter（通常Pythonに標準で含まれています）

## インストール

1. リポジトリをクローンまたはダウンロード

```bash
git clone [リポジトリURL]
cd pdf-compressor
```

2. 必要なパッケージをインストール

```bash
pip install -r requirements.txt
```

### 注意事項

#### tkinterdnd2のインストールについて

`tkinterdnd2`はドラッグ&ドロップ機能に必要なライブラリですが、環境によってはインストールに問題が発生する場合があります。

- **Windows**: 通常問題なくインストールできます
- **macOS**: 追加の設定が必要な場合があります
- **Linux**: システムの`tkdnd`パッケージが必要です

Linuxの場合：
```bash
# Ubuntu/Debian
sudo apt-get install python3-tk tk-dev

# Fedora
sudo dnf install python3-tkinter
```

インストールがうまくいかない場合は、ファイル選択ダイアログ（クリック）による操作が可能です。

## 使い方

1. アプリケーションを起動

```bash
python pdf_compressor.py
```

または、実行可能にする場合：

```bash
chmod +x pdf_compressor.py
./pdf_compressor.py
```

2. PDFファイルを読み込み
   - ドラッグ&ドロップエリアにファイルをドロップ
   - またはクリックしてファイル選択ダイアログから選択

3. 圧縮レベルを選択
   - プリセットから選択、またはカスタムで細かく調整
   - リアルタイムで推定サイズが表示されます

4. 「圧縮開始」ボタンをクリック
   - 進捗バーで処理状況を確認
   - 完了後、元のファイルと同じフォルダに `_compressed.pdf` という接尾辞付きで保存されます

## 技術仕様

- **GUI フレームワーク**: tkinter
- **ドラッグ&ドロップ**: tkinterdnd2
- **PDF処理**: PyMuPDF (fitz)
- **圧縮方式**: 画像をJPEG形式に変換して品質を調整

## 動作原理

1. PDFの各ページを高解像度（144 DPI）で画像としてレンダリング
2. 指定された品質でJPEG圧縮
3. 圧縮された画像を新しいPDFページに挿入
4. ガベージコレクションとdeflate圧縮で最適化

## 制限事項

- テキストベースのPDFは画像化されるため、テキスト選択やコピーができなくなります
- OCR済みのPDFの場合、テキストレイヤーは失われます
- 元々圧縮されているPDFの場合、効果が限定的な場合があります
- 大きなPDFファイル（数百ページ以上）の処理には時間がかかります

## トラブルシューティング

### アプリケーションが起動しない

- Pythonのバージョンを確認してください（3.7以上が必要）
- 必要なパッケージがインストールされているか確認してください

```bash
pip list | grep -E "PyMuPDF|tkinterdnd2"
```

### ドラッグ&ドロップが動作しない

- `tkinterdnd2`が正しくインストールされているか確認してください
- 代わりにクリックしてファイル選択ダイアログを使用できます

### 圧縮率が期待より低い

- 元のPDFが既に圧縮されている可能性があります
- より低い品質設定を試してください
- 画像が多いPDFほど圧縮効果が高くなります

### メモリエラーが発生する

- 非常に大きなPDFファイルの場合、メモリ不足になる可能性があります
- PDFを分割してから圧縮することを検討してください
