# クイックスタートガイド

姿勢評価システムを5分で始める方法

## 📦 インストール

### Windows

1. **Pythonをインストール** (まだの場合)
   - https://www.python.org/downloads/ からPython 3.10をダウンロード
   - インストール時に「Add Python to PATH」にチェックを入れる

2. **セットアップスクリプトを実行**
   ```cmd
   setup.bat
   ```

3. **完了！** アプリケーションを起動
   ```cmd
   python src/main_gui.py
   ```

### Linux/macOS

1. **Pythonを確認** (通常プリインストール済み)
   ```bash
   python3 --version
   ```

2. **セットアップスクリプトを実行**
   ```bash
   chmod +x setup.sh
   ./setup.sh
   ```

3. **完了！** アプリケーションを起動
   ```bash
   python3 src/main_gui.py
   ```

## 📸 写真の撮影方法

### 正面像の撮影

```
👤 被写体の位置:
- カメラの真正面に立つ
- 足を肩幅に開く
- 腕は体の横に自然に下ろす
- リラックスした姿勢

📷 カメラの設定:
- 高さ: 胸の高さ
- 距離: 2〜3メートル
- 全身が写るように
```

### 矢状面像（横向き）の撮影

```
👤 被写体の位置:
- カメラに対して真横を向く
- 足を肩幅に開く
- 腕は体の横に自然に下ろす
- リラックスした姿勢

📷 カメラの設定:
- 高さ: 腰の高さ
- 距離: 2〜3メートル
- 全身が写るように
```

### ✅ 撮影のポイント

- **明るさ**: 自然光が入る明るい場所で撮影
- **背景**: 無地の壁が理想的（白または淡い色）
- **服装**: 体のラインが見える服装（タイトな服、スポーツウェア）
- **画質**: スマートフォンのカメラで十分
- **複数枚**: 何枚か撮影して良いものを選ぶ

## 🖥️ アプリの使い方

### 1. アプリケーション起動

```bash
# Windows
python src/main_gui.py

# Linux/macOS
python3 src/main_gui.py
```

### 2. 画像をアップロード

1. 左側の「正面像」エリアで「📁 画像を選択」をクリック
2. 正面から撮影した写真を選択
3. 右側の「矢状面像」エリアで「📁 画像を選択」をクリック
4. 横から撮影した写真を選択

### 3. 評価を実行

1. 「🔍 姿勢を評価する」ボタンをクリック
2. 数秒待つ（プログレスバーで進捗確認）
3. 評価結果が表示されます

### 4. 結果を確認

- **ケンダル分類**: あなたの姿勢タイプ
- **正面像評価**: 左右のバランス、傾きなど
- **矢状面像評価**: 前後のバランス、姿勢の特徴
- **色の意味**:
  - 🟢 緑 = 良好
  - 🟡 黄 = 注意が必要
  - 🔴 赤 = 改善が必要

### 5. レポートをダウンロード

1. 「📄 A4レポートをダウンロード」ボタンをクリック
2. 保存先を選択
3. PDFファイルが生成されます

## 🎯 よくある質問

### Q: 姿勢が検出されない

**A: 以下を確認してください**
- 全身が写っているか
- 明るい場所で撮影されているか
- 背景と体のコントラストがあるか
- 画像が鮮明か（ブレていないか）

### Q: エラーが出る

**A: 依存パッケージを再インストール**
```bash
pip install -r requirements.txt --force-reinstall
```

### Q: PDFが生成されない

**A: 書き込み権限を確認**
- 管理者権限で実行してみる
- 別のフォルダに保存してみる

### Q: アプリが遅い

**A: スペックを確認**
- RAM: 最低4GB必要
- 画像サイズを小さくする（推奨: 1920x1080以下）

## 🚀 EXEファイルの作成

Pythonをインストールしていない他のPCでも使えるようにEXEファイルを作成:

```bash
python build_exe.py
```

生成されたファイル: `dist/PostureEvaluation.exe`

このEXEファイルを他のWindowsパソコンにコピーするだけで使えます！
